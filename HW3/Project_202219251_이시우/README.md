# 부산 도시철도 환승 경로 추천 프로그램

## 실행 방법
1. Qt Creator 실행
2. `BusanMetroRoute.pro` 열기
3. Desktop Qt Kit 선택
4. Run 실행

## 기능
- 부산 도시철도 노선도 이미지 표시
- 지도 위 역 클릭으로 출발역/도착역 지정
- 최소 환승 경로 탐색
- 최소 정거장 경로 탐색
- 경로를 지도 위에 붉은 선으로 표시
- 최소 시간 기능은 제외

## 좌표 기준
- `images/busan_metro_map.jpg` 원본 크기: 2048 x 626
- 역 좌표는 위 원본 이미지 기준으로 수동 재설정
- 지도 클릭 시 가장 가까운 역을 자동 선택
- 클릭 허용 반경: 약 32px


## v3 수정 사항
- 사용자가 다시 제공한 부산 도시철도 노선도 이미지로 교체했습니다.
- 지도 이미지를 확대/축소하지 않고 원본 크기(2048 x 626) 그대로 표시하도록 변경했습니다.
- 원본 이미지 기준 역 좌표를 다시 보정했습니다.
- 마우스 휠 확대/축소 기능을 제거했습니다.
- 지도 화질 유지를 위해 기본 상태에서 좌표 점 표시를 숨겼습니다.
- 지도 클릭 시 가장 가까운 역을 출발역 또는 도착역으로 지정합니다.


업데이트 사항: 좌표 점을 다시 표시하고, 클릭 판정 반경을 줄여 실제 역 원형 위치에서 더 정확하게 선택되도록 수정함.
